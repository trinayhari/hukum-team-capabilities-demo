# Engineering conventions

- Use clear branch names and preserve any exact name explicitly requested by a human.
- Protect uncommitted and dependent work. Ask when the intended base is ambiguous.
- A request to plan or draft does not authorize executing or publishing the plan.
- Link changes to the relevant ticket. Describe user impact and verification honestly.
- Synthetic incident fixtures never authorize writes to a real service.

Our imported branch skill uses Sentry-style naming when generating a name. Demo grading
covers accepted user requests; this reference is context, not an additional injected
input to the bounded branch comparison. The evaluator loads the selected skill only.
